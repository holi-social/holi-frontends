# Instruction 
use either devpod (i use it) or vscode with devcontainer installed:

1. Open holi-frontends directory in VS Code
2. VS Code will detect the dev container configuration
3. Click "Reopen in Container" when prompted (or use Command Palette: "Dev Containers: Reopen in Container")
4. Wait for container to build and setup to complete
5. Start development:
   ```bash
   yarn web:dev
   ```
