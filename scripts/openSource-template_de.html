holi ist Open Source Software!

"Open Source" bedeutet, dass der Quellcode einer Software offen und frei zugänglich ist. Wir wollen holi mit euch zusammen weiterentwickeln! Hier findet ihr mehr Infos wie ihr mitmachen könnt.

Die Lizenz von holi

holi selber ist unter der GNU AGPL-Lizenz veröffentlicht. Diese gibt euch als Nutzer:innen der Webanwendung das Recht, auf den Source Code zuzugreifen.

Lizenzen anderer Software, die wir nutzen
