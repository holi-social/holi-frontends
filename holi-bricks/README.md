# Holi Bricks

Holi-Bricks is the new components library that works across both mobile and web, providing a consistent and unified design experience. This project utilizes Storybook and Expo to showcase and develop components for both platforms.

### Prerequisites

Make sure you have the following tools installed:

- Node.js (version 20 or later recommended)
- Yarn (4.1.1+)
- Xcode (for iOS simulators)
- Android Studio (for Android simulators)

### Getting Started

- Install dependencies: `yarn`
- Run the project:
  - `yarn web` to launch storybook web
  - `yarn android` to launch storybook on android simulator or device
  - `yarn ios` to launch storybook on ios simulator or device
